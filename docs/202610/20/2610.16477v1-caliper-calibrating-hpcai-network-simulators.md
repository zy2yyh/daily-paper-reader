## 摘要
网络模拟在 HPC/AI 系统研究中发挥着重要作用，它使得能够在实验研究不切实际的规模上探索网络架构、通信策略和系统配置。现有的网络模拟器校准与验证方法缺乏一种原则性方法论，无法将参数对齐、约束推断和独立验证结合起来，面向以集合通信为中心的 HPC/AI 网络。我们提出 CALIPER，一种用于系统化校准和验证 HPC/AI 网络模拟器的方法论。CALIPER 将可直接观测的系统参数与通过校准配置的辅助参数区分开来，并将后者约束为与目标系统一致的可行域。我们利用 Jülich 超级计算中心一个最多 64 节点的参考系统上的集合通信基准，评估 CALIPER 的分层、尺度感知校准及其对参数可辨识性和泛化的影响。验证结果表明，CALIPER 识别出的校准参数配置在纵向扩展和横向扩展网络域中预测系统性能的平均误差低于 5%。CALIPER 表明，分层、受约束的校准能够产生这样的模拟器配置：其预测精度在用于拟合的观测之外仍能保持。

## Abstract
Network simulation plays an important role in HPC/AI system research by enabling exploration of network architectures, communication strategies, and system configurations at scales that may be impractical to study experimentally. Existing approaches to network simulator calibration and validation lack a principled methodology that combines parameter alignment, constrained inference, and independent validation for collective-centric HPC/AI networks. We present CALIPER, a methodology for systematic calibration and validation of HPC/AI network simulators. CALIPER distinguishes directly observable system parameters from auxiliary parameters which are configured via calibration and constrains the latter to feasible domains consistent with the target system. We evaluate CALIPER's hierarchical, scale-aware calibration and its effects on parameter identifiability and generalization using collective communication benchmarks on a reference system with up to 64-nodes at the Jülich Supercomputing Centre. Validation results show that the calibrated parameter configurations identified by CALIPER predict system performance with less than 5% mean errors across scale-up and scale-out network domains. CALIPER demonstrates that hierarchical, constrained calibration can produce simulator configurations whose predictive accuracy persists beyond the observations used for fitting.
