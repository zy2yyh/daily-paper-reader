## 摘要
HPC 应用的仿真是分析系统设计权衡并实现有效软硬件协同设计的重要工具。随着现代超级计算机日益依赖 GPU 加速，MPI 实现已逐步支持 GPU 感知通信，从而实现直接的 GPU 数据传输。因此，对这些机制进行建模对于在当前系统上仿真 HPC 应用至关重要。本文介绍 Orrery，这是一个构建在 SimGrid 的 SMPI 之上的插入层，利用现有的集合通信实现和基于流的仿真来建模 GPU 感知 MPI 通信。Orrery 拦截 GPU 内存分配、内核启动、数据传输和 MPI 操作，并根据目标系统规格在 SimGrid 中建模其执行，从而无需物理 GPU 即可进行仿真。我们使用 CUDA 感知 MPI 微基准测试和一个 Jacobi 求解器，在 MUSICA 超级计算机最多 32 个节点上验证了 Orrery，并证明其复现了关键的 GPU 感知 MPI 机制。

## Abstract
Simulation of HPC applications is an essential tool for analyzing system design trade-offs and enabling effective hardware--software co-design. As modern supercomputers increasingly rely on GPU acceleration, MPI implementations have evolved to support GPU-aware communication, enabling direct GPU data transfers. Modeling these mechanisms is therefore critical for simulating HPC applications on current systems. In this paper, we introduce Orrery, an interposition layer built on SimGrid's SMPI to model GPU-aware MPI communication using existing collective implementations and flow-based simulation. Orrery intercepts GPU memory allocations, kernel launches, data transfers, and MPI operations, and models their execution in SimGrid according to target system specifications, enabling simulation without requiring physical GPUs. We validate Orrery using CUDA-aware MPI microbenchmarks and a Jacobi solver on up to 32 nodes of the MUSICA supercomputer and demonstrate that it reproduces key GPU-aware MPI mechanisms.
