## 摘要
Allreduce 是大规模分布式训练中的基础通信原语，而环面互连仍广泛部署于高性能系统中。我们提出 SP-allreduce，一种面向 d 维环面的新型 allreduce 算法，它利用拓扑的对称性，且仅沿最短路径路由。若一个 allreduce 算法不产生带宽开销、不因多跳导致流量膨胀，并实现每轮完美的负载均衡，则称其为完全带宽最优（fully bandwidth-optimal）。SP-allreduce 基于一族精心对称化的最短路径树，该树族在 α–β 模型中保证完全带宽最优性。我们证明，在 d 维环面上所有完全带宽最优的 allreduce 算法中，它使用的轮数最少，因而在该类算法中运行时间最短。在这个意义上，SP-allreduce 对 Bucket allreduce 进行了改进：它保留了 Bucket 的关键优势，同时将轮数减少一半。我们进一步将该方法扩展到更广泛的对称拓扑以及给定深度的通信树。实验上，在测试配置下，所得算法相较于环面拓扑上对比的最佳先进算法，在方形环面上最高提升 1.19×，在矩形环面上最高提升 1.65×。在 HyperX 和 spine-leaf 网络上，相较于评估的最佳基线，我们分别展示了最高 14.82× 和 1.72× 的增益。

## Abstract
Allreduce is a fundamental communication primitive in large-scale distributed training, and torus interconnects remain widely deployed in high-performance systems. We introduce SP-allreduce, a new allreduce algorithm for $d$-dimensional tori that exploits the symmetry of the topology and routes only along shortest paths.   We call an allreduce algorithm \emph{fully bandwidth-optimal} if it incurs no bandwidth overhead, no multihop-induced traffic inflation, and achieves perfect per-round load balance. SP-allreduce is based on a family of carefully symmetrized shortest-path trees that guarantees full bandwidth optimality in the $α$--$β$ model. We prove that it uses the minimum possible number of rounds among all fully bandwidth-optimal allreduce algorithms on $d$-dimensional tori, and therefore the minimum running time in this class. In this sense, SP-allreduce refines Bucket allreduce: it preserves Bucket's key strengths while reducing the number of rounds by a factor of two.   We further extend our approach to broader symmetric topologies and to communication trees of prescribed depths. Experimentally, the resulting algorithms improve over the best compared state-of-the-art algorithms for tori by up to $1.19\times$ on square tori and $1.65\times$ on rectangular tori across the tested configurations. On HyperX and spine-leaf networks, we demonstrate gains of up to $14.82\times$ and $1.72\times$, respectively, over the best evaluated baselines.

## 1. 核心问题与研究动机

- **背景**：Allreduce 是 HPC 与分布式深度学习（数据并行梯度聚合）的核心通信原语，文献指出集合通信可占大模型训练时长的 40%。环面（torus）互连仍被大量部署：IBM BlueGene/L、Fujitsu 6D Tofu-D（Fugaku、Wisteria、TOKI-SORA、Flow）、Google TPU v5/v6/Ironwood、AWS Trainium Trn1/Trn2、Graphcore IPU-POD 等。
- **模型**：采用 α–β 模型（多端口形式）`T = αS + β·V_avg/D`。小消息时数据传输时间短，**轮数 S 主导总时间**，因此降低轮数是关键。
- **现有方法的矛盾**：
  - Ring allreduce：传输量最小，但需 2(p−1) 轮，线性轮数。
  - 递归倍增/减半倍增：O(log p) 轮，但在环面上通信对端可能相隔多跳，造成链路流量膨胀。
  - Bucket：环面上带宽最优、仅近邻通信，但轮数 2d(n−1) 与环面直径成正比。
  - Swing / Trivance：保持对数轮结构并缩短路由，但未同时满足"零冗余传输 + 一跳路由 + 每轮完美负载均衡"。
- **核心问题**：能否在保持 Bucket 全部带宽优势的前提下，把轮数降到理论下限？
- **分析框架贡献**：论文把带宽代价分解为三个缺陷因子——带宽缺陷 Ψ（相对最小传输量的体积冗余）、多跳路径缺陷 Θ（消息加权平均路径长度）、负载均衡缺陷 Ω（每轮最大链路负载相对平均值的放大），并定义 **完全带宽最优（fully bandwidth-optimal）= Ψ = Θ = Ω = 1**。此时带宽项固定，最小化 α–β 时间等价于最小化轮数。

## 2. 方法论

### 2.1 SP-Allreduce 构造（等边 d 维环面 T_d^n）

- **数据划分**：每节点把向量切成 `2d·n^d` 个等大块，块索引为 (x, ε, j)，x 为归约根，ε 为反射符号，j 为坐标循环移位。
- **基树**：在根 0 处取任意 BFS 树 T0，边朝向根。
- **对称化三步**：
  1. **反射**：坐标取负 u ↦ −u，得 T0⁺ 与 T0⁻；
  2. **循环坐标置换** ρ(u₁,…,u_d) = (u₂,…,u_d,u₁)，施加 d 次；
  3. **平移**到所有根 x。
- **对称群**：Γ = {u ↦ x + ερ^j(u)}，规模 2d·n^d，是环面自同构群的子群，且**在有向物理链路上传递**（平移可达任意位置、置换可达任意轴、反射可反向）。
- **执行**：每棵树深度为环面直径 H = d⌊n/2⌋；reduce-scatter 用 H 轮（自底向上），allgather 反向再用 H 轮，共 **2H = 2d⌊n/2⌋ 轮**；同一轮同一起点/终点/路由的块打包为一条消息。
- **关键引理（轨道均衡，Lemma 3.1）**：同一条有向边轨道上的链路每轮负载相等；若 Γ 在有向边上传递，则每轮最大负载 = 平均负载，即 **Ω = 1**。该论证对任意拓扑、任意基树成立（基树不必是 BFS 树）。

### 2.2 理论保证

- **Theorem 4.1**：SP-allreduce 满足 Ψ = Θ = Ω = 1，运行时间 `T_SP = 2αH + β·2N(p−1)/(pD)`，p = n^d，D = 2d。
- **Theorem 4.2（轮数最优性）**：在所有完全带宽最优方案中，最少轮数为
  - n 为奇数：S_min = 2H；
  - n 为偶数：S_min = 2H − 1。
  SP-allreduce 用 2H 轮 → **奇数 n 时严格最优**，偶数 n 时仅多 1 轮（时间多一个 α）。
- **证明思路（附录 A）**：对单个"基本块"（向量某一位）建立信息流模型，用覆盖数 c(K) 论证至少 2p−2 次传输（Prop. A.1）；等式成立时结构被完全刻画（Lemma A.2）：首个完整聚合轮之前，极大聚合集合互不相交、唯一持有；若多个节点同时变完整，则只能是两个相邻节点交换互补聚合。之后每条传输必须由已完整节点发向未完整节点（Lemma A.4），故需 ≥ ecc 轮扩散。结合环面顶点偏心率 H 与相邻点对联合偏心率 ρ（奇数 n 为 H，偶数 n 为 H−1，Cor. A.5），得下界。
- **偶数 n 的紧性构造（Prop. A.6）**：以两个相邻节点为根的 BFS 森林（深度 H−1）+ 根间一次互补交换 + 反向扩散 = 2H−1 轮，再对称化即得完全带宽最优方案（仅作存在性证明，实验仍用 2H 版本）。

### 2.3 k-SP-Allreduce（允许非近邻通信）

- 允许树边连接非相邻节点，沿最短路径路由，构造**深度受限于 k 的生成树**，轮数降为 2h(T)。
- 此时 Ψ = 1（抽象体积不变），但 **Θ = W(T)/(p−1)**，其中 `W(T) = Σ_{uv∈E(T)} dist_G(u,v)`；Ω 仍为 1。
- 代价模型：`T_model(T) = 2αh(T) + 2βN·W(T)/(pD)`。固定 k 时最小化带宽项 ⇔ 求**最小权重 k 跳生成树**（k=2 已 NP-hard），论文用 ILP 求解（8×8 上可解到最优）。

### 2.4 向其他拓扑扩展

- **矩形环面 T_{m,n}**：Γ = 平移 + 全局反射（2mn 个变换），有**两个有向边轨道**（水平/垂直），单一基树不保证均衡；Theorem 6.1 证明存在**两棵 BFS 树**（逐层各取 ⌊L_ℓ/2⌋ 与 ⌈L_ℓ/2⌉ 条水平边），共 4mn 块，实现 Ψ=Θ=Ω=1、2H 轮（H = ⌊m/2⌋+⌊n/2⌋）。
- **HyperX（K_n □ K_n，直径 2）**：基树为深度 2 的"风车"树（根连接同行同列所有节点，四象限分别挂到列/行交叉点）；群为 Z_n² 平移 + 4 个 90° 旋转，各轨道按规模比例使用边，偶数 n 时 n/2 差轨道边数减半以保持均衡。
- **Spine-leaf（Clos）**：以主机间最短路构造基树，群为主机/叶/脊索引的同步循环移位 h_{i,j} ↦ h_{i+a,j+b}，L_j ↦ L_{j+b}，S_i ↦ S_{i+a}，切 ql 块。
