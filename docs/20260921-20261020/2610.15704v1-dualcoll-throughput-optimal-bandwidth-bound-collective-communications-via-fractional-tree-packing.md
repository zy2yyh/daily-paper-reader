## 摘要
大规模分布式训练日益使集合通信成为带宽受限的环节。在现代 GPU 集群中，NCCL 等通信库在 NVLink、InfiniBand 和以太网等异构互连上实现包括 AllReduce 在内的集合操作，因此高效利用可用网络带宽成为核心的系统挑战。ForestColl 表明，此类网络结构上的集合通信可以用分数树打包来建模；其可扩展的多项式时间构造针对 AllGather 开发，而 AllReduce 则通过组合 AllGather 与 ReduceScatter 获得。我们提出 DualColl，直接面向带宽受限的 AllReduce。在基于树的 AllReduce 模型下，DualColl 应用 Garg–Könemann 风格的多重权重算法，并且对于任意 0<ε<1，计算出一个可行调度，其吞吐至少为最优 AllReduce 吞吐的 (1-ε)^2。其关键组件是一个精确的最小代价集合树 oracle，它将物理链路的对偶价格投影到参与 rank 的逻辑图上，从而将每次迭代归约为最短路径计算，随后进行最小生成树计算。我们进一步将该框架扩展到本地等下一跳的包喷洒路由，以及没有显式逐树带宽控制的网络。对于后者，我们引入树耦合的最大最小带宽共享模型，并证明树复制能以可证明的精度-复杂度权衡逼近显式的分数分配。最后，我们将分数打包框架扩展到其他集合操作以及多个并发集合组。

## Abstract
Large-scale distributed training increasingly makes collective communication bandwidth-bound. In modern GPU clusters, communication libraries such as NCCL implement collectives including AllReduce over heterogeneous interconnects such as NVLink, InfiniBand, and Ethernet, making efficient use of available network bandwidth a central systems challenge.   ForestColl showed that collective communication on such fabrics can be formulated using fractional tree packing; its scalable polynomial-time construction is developed for AllGather, with AllReduce obtained by composing AllGather and ReduceScatter. We present DualColl, which targets bandwidth-bound AllReduce directly. Under the tree-based AllReduce model, DualColl applies a Garg--Könemann-style multiplicative-weights algorithm and, for any $0<ε<1$, computes a feasible schedule whose throughput is at least $(1-ε)^2$ of the optimal AllReduce throughput. Its key component is an exact minimum-cost collective-tree oracle that projects physical-link dual prices onto a logical graph of participating ranks, reducing each iteration to shortest-path computations followed by a minimum spanning tree.   We further extend the framework to local equal-next-hop packet-sprayed routing and to networks without explicit per-tree bandwidth control. For the latter, we introduce a tree-coupled max-min bandwidth-sharing model and show that tree duplication approximates an explicit fractional allocation with a provable accuracy-complexity tradeoff. Finally, we extend the fractional-packing framework to additional collective operations and multiple concurrent collective groups.

## 1. 核心问题与研究动机

- **背景**：大规模分布式训练（数据并行、张量并行、流水并行、专家并行及分布式推理）中，AllReduce 等集合通信日益成为**带宽受限**环节。GPU 集群由 NVLink/NVSwitch（节点内）与 InfiniBand/Ethernet（节点间）等异构互连构成，且各层存在不同程度的超额订阅，因此需要能感知拓扑与容量的通信调度。
- **已有基础**：ForestColl 将带宽受限集合通信建模为**分数树打包（fractional tree packing）**——每棵逻辑生成树以连续速率 λ_T 承载数据分片，在物理链路容量约束下最大化总树带宽。该抽象被证明是吞吐最优的。
- **关键缺口**：ForestColl 的多项式时间构造针对 **AllGather** 开发，AllReduce 通过“AllGather + ReduceScatter”组合得到。论文附录 A 给出反例：5 个 rank 的路径拓扑（每条链路双向容量 4），一组 AllGather 最优（β=1）的树集在组合成 AllReduce 后使链路 {1,2} 每单位带宽负载达 6，聚合带宽仅 10/3；而直接采用单棵路径树可跑满带宽 4，严格更优。**组合最优性不能传递到 AllReduce**。
- **研究含义**：需要一个**直接面向 AllReduce**、具备**可证明近优保证**且**多项式时间**的算法，并能延伸到包喷洒路由、无逐树带宽控制、多并发通信组等真实部署形态。

## 2. 方法论

### 2.1 网络与问题建模

- **物理网络**：有向图 G=(V∪S, E)，V 为计算节点（rank），S 为交换机；每条有向边 e 有容量 C_e>0；全双工物理链路用两条反向有向边表示，假设两方向容量相等（C_e = C_ē）。
- **树基 AllReduce**：逻辑生成树 T 覆盖参与 rank R，每条逻辑边由调度器映射到**单条**物理路径。树 T 以速率 λ_T **同时**进行 reduce（叶→根）与 broadcast（根→叶）。
- **链路占用系数** A_{e,T}：树 T 单位带宽下对物理边 e 的容量消耗（即穿越 e 的逻辑树边数，可大于 1）。
- **分数树打包 LP**：
  - max Σ_{T∈S} λ_T
  - s.t. Σ_{T∈S} A_{e,T} λ_T ≤ C_e, ∀e∈E；λ_T ≥ 0
  - 记最优值为 OPT；虽然候选树集合 S 指数大，但约束数多项式，故最优解只需多项式多棵树。
- **吞吐等价性**：设每 rank 收发 X 单位数据，树 T 分得 x_T，完成时间 τ_T = x_T/λ_T；按 x_T ∝ λ_T 分配可使所有树同时完成，τ = X/Σλ_T；Lemma 2.2 证明任意分配下必有某树不早于 X/Λ 完成，故**最大化 Σλ_T 等价于最小化完成时间**（稳态、带宽主导、忽略启动与流水填充/排空）。

### 2.2 树基 AllReduce 不损失吞吐（Theorem 2.1 / 3.7）

从任意带宽最优调度出发，经三步规范化且不增加任何边负载与完成时间：

1. **Lemma 3.1**（提升为完全归约分片）：若某流源已持有完全归约值，可沿依赖链把载荷替换为完全归约值，调度仍合法（依赖关系无环，按拓扑序处理）。
2. **Lemma 3.2**（同分片内速率相等）：丢弃无用流后，把所有流速率统一降到最小值 b_min，分片完成时间仍为 s/b_min，边负载不增。
3. **Lemma 3.3**（提升不变慢）：等速率下提升只改载荷不改路由与速率，故不变慢。
4. **Lemma 3.4**（单根）：对 k≥2 个根按服务集合划分，取“最后一个跨组流”进行提升，可消去一个根而不增负载。
5. **Lemma 3.5**（每阶段为树）：在 send 图上按到根的最短距离选边，分别构造入树（reduce）与出树（broadcast），只保留原流子集。
6. **Lemma 3.6**（reduce 与 broadcast 树可合并）：对每棵入树 R_i 与出树 D_i 构造两棵“简单树”，各分速率 λ_i/2、各承载半个分片；利用单路径路由下反向边负载镜像的性质，新负载为原两方向负载的**平均值**，不超过原最大值，故仍可行。

> 结论：在调度器单路径路由 + 全双工对称容量下，存在仅由“简单树”构成的带宽最优 AllReduce 调度，OPT 即真实最优吞吐。

### 2.3 DualColl 主算法（Algorithm 1）

Garg–Könemann 风格乘法权重框架：

- **初始化**：γ = (1+ε)·((1+ε)m)^{-1/ε}（m=|E|），y_e ← γ/C_e，λ_T ← 0。
- **迭代**（直到对偶长度 D(y)=Σ_e C_e y_e ≥ 1）：
  1. 调用**最小代价集合树 oracle**，在当前价格 y 下求最小化 Σ_e A_{e,T} y_e 的树 T★；
  2. 计算瓶颈增量 Δ = min_{e: A_{e,T★}>0} C_e / A_{e,T★}；
  3. λ_{T★} ← λ_{T★} + Δ；
  4. 对 T★ 使用的每条物理边做乘法更新：y_e ← y_e·(1 + ε·A_{e,T★}·Δ/C_e)。
- **终止缩放**：λ̂_T = λ_T / log_{1+ε}((1+ε)/γ)，得到满足容量约束的可行打包。
- **近似保证（Theorem 4.2）**：对任意 0<ε<1，Σ_T λ̂_T ≥ (1−ε)²·OPT。

### 2.4 最小代价集合树 Oracle（核心创新）

- **对偶价格投影**：对每对 rank (u,v)，令 d_y(u,v) 为以 y_e 为边权的最短路径距离；逻辑无向边 {u,v} 的投影权重为
  **W_{u,v} = d_y(u,v) + d_y(v,u)**（reduce 与 broadcast 两方向之和）。
- 在逻辑完全图 G_R=(R, E_R)（顶点仅为参与 rank，交换机不显式出现）上求 **MST**；对每条被选逻辑边记录两方向的最短物理路径。
- **正确性（Theorem 4.1）**：依赖**路由可分离性假设**——各逻辑边的物理路由可独立选择，故固定逻辑树的物理代价可分解为各边投影权重之和，最小化即 MST 问题；从而 oracle 返回全局最小对偶代价的路径化集合树，无需枚举指数多候选树。

### 2.5 复杂度

- 单次 oracle：O(n(|E|+N)log N + n²)，其中 n=|R|、N=|V∪S|（n 次 Dijkstra + 稠密图 Prim）。
- 迭代次数：O(|E|log|E|/ε²)。
